# Contributing

Спасибо, что хочешь поучастствовать. Всё держится на одном правиле:
**не сломай совместимость с WARP и не ломай чужие версии AmneziaWG.**

## Перед отправкой PR

```bash
bash -n warp_generator.sh          # синтаксис
bash warp_generator.sh --self-test  # все версии + негативные тесты
```

`--self-test` обязан завершиться строкой
`SELF-TEST ПРОЙДЕН: все версии генерируются и валидны` и кодом возврата `0`.

## Правила

1. **Версия — это контракт.** Добавляешь новый AWG-ключ? Обязательно:
   - проверь, что он есть в реальном `amneziawg-tools` (`src/config.c`, ветка `key_match()`)
   - добавь его в `key_allowed()` с правильной версией
   - добавь негативный тест, что в более старой версии он отвергается
2. **On-wire параметры для WARP нейтральны.** `S1..S4 = 0`, `H1..H4 = 1/2/3/4`,
   нет `HeaderProtectionKey`, `ContentPaddingAddition = 0`. Любое изменение
   формата пакета убивает туннель до WARP. Валидатор это проверяет.
3. **Версия должна совпадать.** После сборки конфига прогоняй `detect_awg_version()`
   и сравнивай с запрошенной. Несовпадение — ошибка, а не warning.
4. **Только POSIX + bash 3.2.** Нет ассоциативных массивов, `${var^^}`,
   `mapfile`, `readarray`. `jq`, `wg`, `awg`, `apt` — опциональны, на каждый
   обязан быть фолбэк.
5. **Комментарии по делу.** Объясняй *почему*, а не *что*. Ссылки на строки
   исходников (`amnezia-client/.../awgProtocolConfig.cpp:awgVersionOf()`) приветствуются.

## Чего делать не надо

- Не хардкодить URL или аккаунты — используй плейсхолдер `<ТВОЙ_АККАУНТ>`
- Не добавлять зависимости, которые нельзя заменить фолбэком
- Не коммитить сгенерированные `*.conf` и `vpn://`-ссылки — там приватные ключи
